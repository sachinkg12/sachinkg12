# Profile appearance

This profile follows the visual style of https://sachinkg12.github.io/:
white surfaces, dark sans-serif text, italic serif accents, thin gray borders,
pill-shaped links, and pale yellow and leaf-green illustration panels.

The original desk illustration is copied unchanged from
https://sachinkg12.github.io/assets/sachin-desk-illustration.webp.
It is embedded in the banner SVGs so the images remain self-contained.
The existing portrait remains available in `portrait.png`.

The existing nine research descriptions and project links are preserved. Responsive research and project rows replace the cramped grids;
reviewing roles use native headings and linked text. The SCIS 2026 keynote is
now featured, and marketplace activity separates the owner’s dated acquisition
figure from automatically refreshed public download/install counters.
The community words are unchanged.
The waving hand and reduced-motion support are preserved.

GitHub profile READMEs do not support the website’s full CSS or JavaScript.
GitHub controls paragraph fonts. Main section headings use outlined artwork;
the local preview provides a font toggle to compare website and GitHub body text.

The latest revision removes the repeated marketplace footnote and distribution
caption, including from future automated count refreshes. Section rules and the
internal row dividers are replaced by spacing. Main headings combine Arial with
Lora italics and retain named anchors. The website section links both the portfolio
at sachinkg12.github.io and the writing site at guptasachinn.com. The word-cloud
background uses the talks card’s exact yellow token, with dark, contrasting text.
